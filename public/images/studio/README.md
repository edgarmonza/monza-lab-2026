# MONZA STUDIO — GALERÍA VISUAL

Deja aquí las fotos que quieras mostrar en la sección Monza Studio de la web.

## 📁 Estructura

- `fashion/` — fotos de proyectos de moda, lookbooks, campañas, editorial
- `automotive/` — fotos de autos, microbrands, carros clásicos, detalles

## 📐 Recomendaciones

- **Formato**: JPG o WebP
- **Tamaño**: 1600×2000 px (vertical 4:5) o 2000×1600 (horizontal 5:4) ideal
- **Peso**: máx 500KB por foto (comprimir antes — usa squoosh.app o tinypng.com)
- **Nombres**: sin espacios, en inglés, descriptivos. Ej:
  - `fashion/eleonora-editorial-01.jpg`
  - `automotive/bavarian-econs-bmw-2002-01.jpg`

## 🎨 Orden
Los nombres alfabéticos definen el orden de aparición. Usa prefijos numéricos si quieres controlarlo:
- `01-hero-image.jpg` aparecerá primero
- `02-second-image.jpg` después
